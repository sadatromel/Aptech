DATABASE STRUCTURE (8 TABLES)
================================================================================

1. user_roles
   - role_id (Primary Key)
   - role_name (Super Admin, Manager, Technician, Viewer)
   - role_description
   - is_active
   - timestamps

2. users
   - user_id (Primary Key)
   - full_name
   - email (UNIQUE)
   - password_hash
   - role_id (Foreign Key)
   - active_type (active, inactive, suspended)
   - last_login
   - timestamps

3. user_activity_logs
   - log_id (Primary Key)
   - user_id (Foreign Key)
   - activity_type
   - activity_desc
   - activity_time
   - ip_address

4. vehicles
   - vehicle_id (Primary Key)
   - registration_number (UNIQUE)
   - vehicle_name
   - make
   - model
   - year
   - vehicle_type
   - fuel_type
   - current_mileage
   - purchase_date
   - purchase_cost
   - status (active, inactive, retired)
   - created_by (Foreign Key)
   - timestamps

5. maintenance_schedule
   - schedule_id (Primary Key)
   - vehicle_id (Foreign Key)
   - maintenance_type
   - description
   - scheduled_date
   - completed_date
   - cost
   - status (pending, completed, cancelled)
   - notes
   - created_by (Foreign Key)
   - timestamps

6. parts_inventory
   - part_id (Primary Key)
   - part_name
   - part_code (UNIQUE)
   - category
   - quantity_in_stock
   - reorder_level
   - unit_price
   - supplier
   - last_restocked
   - created_by (Foreign Key)
   - timestamps

7. maintenance_parts_usage
   - usage_id (Primary Key)
   - maintenance_id (Foreign Key)
   - part_id (Foreign Key)
   - quantity_used
   - unit_price
   - total_cost

8. cost_reports
   - report_id (Primary Key)
   - vehicle_id (Foreign Key)
   - report_month
   - maintenance_cost
   - parts_cost
   - fuel_cost
   - other_cost
   - total_cost (auto-calculated)
   - created_by (Foreign Key)
   - created_at
