================================================================================

STEP 2.1: CREATE DATABASE

Method A - Using phpMyAdmin:
  1. Open http://localhost/phpmyadmin in browser
  2. Click "Databases" tab
  3. Enter database name: aptech
  4. Select Collation: utf8mb4_unicode_ci

Method B - Using MySQL Command Line:
  1. Open Command Prompt
  2. Type: mysql -u root
  3. Execute: CREATE DATABASE aptech;

SECTION 6: TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot connect to database"
SOLUTION:
  1. Check MySQL is running (XAMPP Control Panel)
  2. Verify database 'aptech' exists in phpMyAdmin
  3. Check database credentials in PHP files
  4. Default: Host=localhost, User=root, Password=(blank)
  5. If different, update credentials in each PHP file

PROBLEM: "Page not found / 404 error"
SOLUTION:
  1. Verify files are in: C:\xampp\htdocs\AIP Transport\
  2. Check folder name spelling (case-sensitive on Linux)
  3. Restart Apache server
  4. Clear browser cache (Ctrl+F5)
  5. Try accessing http://localhost/AIP%20Transport/index.php

PROBLEM: "Foreign key constraint fails when adding data"
SOLUTION:
  1. Database not properly imported
  2. Delete database and try again:
     - In phpMyAdmin, select database 'aptech'
     - Click "Drop" (delete)
     - Create new 'aptech' database
     - Re-import complete_setup.sql
  3. Ensure roles are created before adding users

PROBLEM: "Login not working"
SOLUTION:
  1. Check database has sample users (3 users should exist)
  2. Verify email is correct: admin@aiptransport.com
  3. Password: password123 (case-sensitive)
  4. Check PHP error logs
  5. Try different browser
  6. Clear cookies

PROBLEM: "Session expires immediately"
SOLUTION:
  1. Check PHP session settings
  2. Session timeout usually 24 minutes by default
  3. No files are corrupted
  4. Just login again

PROBLEM: "Blank page or white screen"
SOLUTION:
  1. PHP error occurred - check error logs
  2. Enable PHP error display:
     - Edit php.ini
     - Find: display_errors = Off
     - Change to: display_errors = On
  3. Restart Apache
  4. Refresh page to see errors
  5. Most common: Database connection issue

PROBLEM: "Can't upload files to folder"
SOLUTION:
  1. Check folder permissions
  2. Folder must be writable
  3. Right-click folder → Properties
  4. Security → Edit → Modify (Allow checkbox)
  5. Apply and OK

SECTION 8: BACKUP & RECOVERY
================================================================================

REGULAR BACKUPS:

Database Backup (Weekly):
  1. Open phpMyAdmin
  2. Select 'aptech' database
  3. Click "Export" tab
  4. Select "SQL" format
  5. Click "Go"
  6. Save file to backup location
  7. Name it with date: aptech_backup_2025-11-24.sql

Files Backup (Monthly):
  1. Copy entire folder: AIP Transport
  2. Rename: AIP Transport_backup_2025-11
  3. Store in separate location
  4. Keep at least 3 backups

RECOVERY PROCEDURE:

Database Recovery:
  1. Drop corrupted database in phpMyAdmin
  2. Create new 'aptech' database
  3. Import backup SQL file
  4. Verify all data restored

File Recovery:
  1. Delete corrupted files
  2. Copy from backup folder
  3. Paste to original location
  4. Restart Apache
