QUICK START (5 MINUTES):

1. Create Database
   - Open phpMyAdmin at http://localhost/phpmyadmin
   - Create new database named 'aptech'

2. Import Schema
   - In aptech database, click Import
   - Select 'complete_setup.sql' file
   - Click Go

3. Access System
   - Open http://localhost/AIP%20Transport/
   - Login: admin@aiptransport.com / password123

4. Start Using

   - Log maintenance
