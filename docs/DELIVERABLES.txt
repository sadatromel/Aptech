================================================================================
                        SETUP INSTRUCTIONS
================================================================================

STEP 1: CREATE DATABASE
  1. Open phpMyAdmin
  2. Create new database named 'aptech'
  3. Select UTF-8 (UTF-8 UNICODE CI) encoding

STEP 2: IMPORT SCHEMA
  1. Go to 'aptech' database
  2. Click 'Import' tab
  3. Select 'complete_setup.sql' file
  4. Click 'Go'
  5. Wait for completion message

STEP 3: PLACE FILES
  1. Extract all PHP files
  2. Place in C:\xampp\htdocs\AIP Transport\
  3. Keep file structure intact

STEP 4: START SERVERS
  1. Start XAMPP/WAMP
  2. Start Apache server
  3. Start MySQL server

STEP 5: ACCESS SYSTEM
  1. Open web browser
  2. Go to http://localhost/AIP%20Transport/
  3. Login with admin@aiptransport.com
  4. Password: password123
